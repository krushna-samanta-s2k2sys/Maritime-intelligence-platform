Risk Register

RiskSeverityProbabilityMitigation
D6 connector development takes longer than planned HIGH MEDIUM Prioritise top 50 feeds for M3 milestone; remaining 150 feeds can follow. Buffer 2 months allocated in Phase 1. Direct D6 team engagement in M1.
Terahelix / Gearbox integration complexity exceeds estimates HIGH MEDIUM Engage Terahelix/Gearbox product teams in M2. Prototype integration in M3. Gold layer can launch without full Gearbox if needed (relationships added incrementally).
Historical data quality is worse than expected MEDIUM HIGH Phase 6 assessment week identifies issues early. Migration uses the same Silver-layer DQ framework. Partial migration is acceptable — launch with current data and backfill continues post-launch.
AI confidence scoring model underperforms MEDIUM MEDIUM Source hierarchy rules-based fallback is available without the ML model. Lower auto-apply thresholds initially and raise as model accuracy improves through feedback loop.
Key contractor personnel unavailable mid-project HIGH LOW Ensure knowledge is documented in wikis and Terraform code from M1. Contractor contracts include key-person clauses. FTE teams shadow contractors on critical deliverables.
Okta or Apigee configuration delays block delivery MEDIUM LOW Start Okta configuration in M1 (Phase 0). Apigee can be bypassed temporarily with internal JWT validation — never blocks feature development.
BigQuery cost overrun from unoptimised queries MEDIUM MEDIUM BigQuery slot reservations cap costs. All ad-hoc queries go through Cloud Run service (never directly from UX). Cost anomaly alerts configured from M1. Elasticsearch handles all search — BigQuery not hit by user queries.
Pen test finds critical security issues late in project HIGH LOW Security design reviewed in M1-M2. VPC Service Controls and column-level security designed in from the start. Pen test in M10-M11 leaves 4–8 weeks to resolve findings before launch.
Scope creep from new feature requests MEDIUM HIGH Architecture review board approves scope changes only. New requests go to backlog for post-launch. Program manager accountable for scope gate. Monthly steering committee review.

Definition of Success

The platform is considered successfully launched when all of the following are met:

Data Quality
  • >99% of active vessels have Gold records
  • >95% completeness score on priority vessels
  • <5% of vessel fields in review queue (AI auto-applies the rest)
  • Zero accidental overwrites to Gold master
Performance
  • Search p95 < 200ms
  • API p99 < 500ms
  • API availability 99.9% over 30 days
  • Feed ingestion SLA met 99% of the time
Adoption
  • All 8 persona types actively using the platform
  • At least 1 external customer on API v1
  • Snowflake and EDO-Fabric data products live
  • Legacy system decommissioned or read-only
Post-launch roadmap items (not in scope for 12-month plan): AI model v2 (expanded training data), mobile application, additional AIS data providers, customer-facing self-service API portal, Kafka migration for real-time AIS streaming, and automated sanctions screening integration.
