Port Schema

Bi-temporal EAV store for port attributes, a PostGIS geometry table for precise location data (with GENERATED columns for lat/lon from the geometry), annual range partitions, and a wide v_current materialized view that flattens all channel, berth, service, bunker, traffic and PSC attributes into named columns aligned with ports_detail.json.

6 tables + 1 mat. view UNLOCODE primary key PostGIS GEOMETRY(Point,4326) GENERATED lat/lon columns attr_value: 4 annual partitions insert-only attr_value (RULE)

port Schema Tables

port.entity

Purpose: Anchor table — one row per port. The UNLOCODE (UN Location Code, 5 chars e.g. 'SGSIN') is the primary key and universal join key. Mirrors gis_ports.json "locode" field. Referenced by voyage.port_call, compliance.psc_inspection, market.freight_rate etc.

port.attr_value — Silver Layer (vendor data)

Purpose: Bi-temporal EAV for all port attributes from vendor sources. Structurally identical to vessel.attr_value but keyed by unlocode. Insert-only by RULE. Partitioned annually. The workflow_state here reflects QC status only — promotion to master requires an explicit workflow.promotion_request approval. port.v_current reads from port.master_value, not this table. Covers all attributes in ports_detail.json: identity, channel limits, berths, services, bunkering, traffic, PSC, certification.
INSERT-ONLY RULES:
CREATE RULE port_av_no_update AS ON UPDATE TO port.attr_value DO INSTEAD NOTHING;
CREATE RULE port_av_no_delete AS ON DELETE TO port.attr_value DO INSTEAD NOTHING;

port.location

Purpose: PostGIS geometry table for port location. NOT EAV — geometry changes rarely and requires spatial indexing. Uses GENERATED ALWAYS AS columns to extract latitude/longitude from the geometry so queries can use either numeric coordinates or the PostGIS geometry. Mirrors gis_ports.json coordinate fields.

port Materialized View

port.v_current (Materialized View)

Purpose: Wide current-state view of the master record. Reads exclusively from port.master_value (gold layer). Column names match ports_detail.json field paths. Also JOINs port.location for coordinates and geometry. Refreshed CONCURRENTLY via registry.refresh_all_current_views(). Serves the port detail panel, GIS map layer, and PSC analytics pages. For vendor comparison, query port.attr_value directly.

port.v_current Column Groups (pivoted from master_value using CASE WHEN attr_key = '...' THEN ...)

Identity (ports_detail.json: name, fullName, country, region, type, status, mou)
name = port_name  ·  full_name = port_full_name  ·  country  ·  region  ·  type = port_type  ·  status = port_status  ·  mou = psc_mou  ·  wpi = wpi_number  ·  authority = port_authority  ·  established = year_established  ·  eca_zone  ·  seca_zone
Channel Limits (ports_detail.json: channel.maxDraft, maxLoa, maxBeam, nightEntry)
ch_max_draft_m  ·  ch_max_loa_m  ·  ch_max_beam_m  ·  ch_max_dwt  ·  ch_max_air_draft_m  ·  night_entry
Berths (ports_detail.json: berths.count, maxLoa, maxDraft)
berth_count  ·  berth_max_loa_m  ·  berth_max_draft_m
Services (ports_detail.json: services.*)
pilotage  ·  pilotage_compulsory  ·  towage  ·  tugs = tug_count  ·  freshwater  ·  drydock  ·  drydock_count  ·  vts = vts_available
Bunkering (ports_detail.json: bunker.*)
bunker_available  ·  bunker_hfo  ·  bunker_vlsfo  ·  bunker_mgo  ·  bunker_lng  ·  bunker_methanol
Traffic & Congestion (ports_detail.json: traffic.*, congestion.*)
annual_calls  ·  annual_cargo = annual_cargo_mt  ·  teu = annual_teu  ·  world_rank  ·  avg_waiting_hrs  ·  avg_turnaround_hrs  ·  congestion_risk
PSC Record (ports_detail.json: psc.*)
psc_total_insp  ·  psc_detentions  ·  psc_det_rate_pct  ·  psc_avg_def
Location (from port.location JOIN)
latitude  ·  longitude  ·  geom  ·  timezone  ·  utc_offset  ·  coastline
