Registry & Ingest Schemas

The foundation of the Maritime Intelligence Platform database. The registry schema is the single source of truth for all attribute definitions, data sources and UI configuration. The ingest schema manages ETL feed lifecycle, field mappings, QC rules and conflict resolution.

9 tables 8 indexes source_def → 29 seed rows insert-only: audit.change_log versioned field maps

registry Schema Attribute catalog & source registry

registry.source_def

Purpose: Vendor / data-source registry. Every row in attr_value, raw_ingest, position etc. must reference a valid source_id. Seeded with 29 rows from etl_feeds.json (IHS Markit, Equasis, Orbcomm AIS, flag registries, class societies, PSC MOU authorities, OFAC, EU Sanctions).
