Company Schema

Three-layer architecture: Bronze (raw_ingest) → Silver (attr_value, vendor data, insert-only) → Gold (master_value, explicitly approved) → v_current materialized view. Covers fleet composition, financial metrics, credit ratings, KYC status, ESG scores and sanctions status. Supports multiple company ID systems (LRNO, LEI, DUNS). Vendor data requires explicit promotion approval before reaching the master layer.

5 tables + 1 mat. view Multi-ID: LRNO · LEI · DUNS attr_value: 4 annual partitions insert-only attr_value (RULE) KYC + ESG + sanctions columns CONCURRENT refresh

company Schema Tables

company.entity

Purpose: Anchor table — one row per maritime company. Supports three external ID systems in addition to the internal company_id: LRNO (Lloyd's Register Number), LEI (Legal Entity Identifier, 20 chars, ISO 17442), DUNS (Dun & Bradstreet, 9 digits). All external IDs are unique-indexed for fast cross-system resolution. Mirrors gis_companies.json "id" field.

company.attr_value — Silver Layer (vendor data)

Purpose: Silver layer — bi-temporal EAV for all inbound vendor company attributes. Insert-only by RULE. Records every data point as received from external providers (Clarksons, OFAC, KYC vendors, credit agencies). Does NOT drive the UI directly. Data must pass through workflow.promotion_request and be explicitly approved before it is written to company.master_value (gold layer). Covers all attributes in companies_detail.json: identity, fleet metrics, DOC/ISM certification, PSC history, financial KPIs, credit ratings, sanctions screening, KYC status and ESG scores.
INSERT-ONLY RULES:
CREATE RULE company_av_no_update AS ON UPDATE TO company.attr_value DO INSTEAD NOTHING;
CREATE RULE company_av_no_delete AS ON DELETE TO company.attr_value DO INSTEAD NOTHING;

company.master_value — Gold Layer (approved master data)

Purpose: Gold layer — holds only explicitly approved company attribute values. Written by four paths: (1) Vendor promotion — approved workflow.promotion_request; (2) Manual entry — reviewer approves an workflow.edit_draft with source_type='MANUAL'; (3) Backdated insert — any of the above with valid_from set to a past date; (4) Auto-promotion — when registry.source_attr_weight.auto_promote_to_master = TRUE for fully trusted source+attribute pairs (e.g. OFAC sanctions flag). v_current reads exclusively from this table, never from attr_value.

company Materialized View

company.v_current (Materialized View)

Purpose: Wide current-state view — one row per company with all approved attributes pivoted into named columns. Reads exclusively from company.master_value (gold layer) — only explicitly promoted or manually entered values appear here. Also includes the entity-level multi-ID fields (id_type, lrno, lei, duns) directly from company.entity. Column names match companies_detail.json field paths. Refreshed CONCURRENTLY. Serves the company detail panel, GIS company layer and compliance analytics.

company.v_current Column Groups — pivoted from master_value (gold layer)

Entity IDs (from company.entity directly)
company_id · id_type · lrno · lei · duns
Identity (companies_detail.json: name, fullName, country, city, type, status, roles)
name = company_name  ·  full_name = company_full_name  ·  type = company_type  ·  status = company_status  ·  country = country_of_control  ·  city  ·  roles = company_roles  ·  established = established_year
Fleet (companies_detail.json: fleet.owned, fleet.managed, fleet.totalDwt, fleet.avgAge)
vessels_owned = fleet_owned  ·  vessels_managed = fleet_managed  ·  total_dwt_mt = fleet_total_dwt  ·  avg_fleet_age = fleet_avg_age
DOC & ISM Certification (companies_detail.json: doc.*, ism.*)
doc_issued  ·  doc_expiry  ·  ism_audit_date  ·  ism_status
PSC Record (companies_detail.json: psc.*)
psc_total_insp  ·  psc_detentions  ·  psc_det_rate_pct
Financial (companies_detail.json: financial.revenue, ebitda, netProfit)
revenue_usd_m = revenue_usd  ·  ebitda_usd_m = ebitda_usd  ·  net_profit_usd_m = net_profit_usd
Credit (companies_detail.json: credit.rating, agency, outlook)
credit_rating  ·  credit_agency  ·  credit_outlook
Sanctions (companies_detail.json: sanctions.clear, screenedAt)
sanctions_clear (BOOLEAN)  ·  sanctions_screened_at
KYC (companies_detail.json: kyc.status, reviewedAt, riskLevel)
kyc_status  ·  kyc_reviewed_at  ·  kyc_risk_level
