Vessel Schema

The most complex entity schema in the platform. Uses a three-layer data model: silver layer (attr_value — insert-only vendor data), gold layer (master_value — explicitly approved master record), and bronze layer (raw_ingest). Plus a high-volume AIS position stream, two materialized views, and a vessel-level source preference table. Values only enter master via an approved workflow.promotion_request or workflow.edit_draft.

8 tables + 2 mat. views Silver: attr_value — 11 partitions (yearly) Gold: master_value — 11 partitions (yearly) position: 10 partitions (quarterly) insert-only attr_value & master_value PostGIS GIST index on position CONCURRENT refresh v_current reads from master_value

vessel.entity

Purpose: Anchor table — one row per vessel. The IMO number is the primary key and the universal join key across all vessel tables. All EAV values, positions, PSC inspections, voyages and market records reference imo_number here.

vessel.attr_value — Silver Layer (vendor data)

Purpose: Bi-temporal EAV store for all raw vendor-sourced attribute values. Insert-only — no updates or deletes permitted (enforced by PostgreSQL RULE). Each row records one value from one source at one point in time. This table does NOT drive the UI — it is the vendor/source audit layer. The workflow_state here reflects QC status only (PENDING = QC running, APPROVED = QC passed, REJECTED = QC blocked). Promotion to master requires an explicit workflow.promotion_request approval; vessel.v_current now reads from vessel.master_value, not this table.
INSERT-ONLY RULES (prevents data loss):
CREATE RULE vessel_av_no_update AS ON UPDATE TO vessel.attr_value DO INSTEAD NOTHING;
CREATE RULE vessel_av_no_delete AS ON DELETE TO vessel.attr_value DO INSTEAD NOTHING;

vessel.master_value — Gold Layer (master record)

Purpose: The explicitly curated golden record for vessel attributes. A row enters here only via: (a) an APPROVED workflow.promotion_request → entry_type VENDOR_PROMOTED or CONFLICT_RESOLVED; (b) an APPROVED workflow.edit_draft → entry_type MANUAL_ENTRY or BACKDATED. Insert-only: supersede a row by setting its sys_to / valid_to before inserting the replacement. vessel.v_current is built exclusively from this table. Full provenance is maintained via source_av_id (back-link to the vendor row) and pr_id / draft_id.

vessel.attr_source_preference

Purpose: Vessel-level source trust preference. Records which data vendor a user prefers for a specific attribute on a specific vessel. Used by the confidence scoring engine when generating workflow.promotion_request records — it boosts the preferred vendor's request to appear first in the review queue. Does NOT auto-promote: it is a hint only. Overrides the global registry.source_attr_weight for this vessel+attribute combination.

vessel.v_current (Materialized View)

Purpose: Wide, pivoted, current-state view of the master record. Reads exclusively from vessel.master_value (gold layer) — only values that have been explicitly approved appear here. Column aliases exactly match vessels.js VESSELS property names so the API layer needs zero field remapping. Refreshed CONCURRENTLY after each ingest+promotion cycle via registry.refresh_all_current_views(). For vendor comparison across multiple sources, query vessel.attr_value directly.

v_current Column Groups (pivoted from master_value using CASE WHEN attr_key = '...' THEN ...)

Identity (vessels.js: nm, imo, mmsi, cs, fn, fl, ty, st, up)
nm = vessel_name  ·  imo = imo_number  ·  mmsi = mmsi_number  ·  cs = call_sign  ·  fn = flag_name  ·  fl = flag_code  ·  ty = vessel_type  ·  st = vessel_status  ·  up = last_updated
Dimensions (vessels.js: loa, lbp, beam, depth, maxDraft, sumDraft)
loa_m  ·  lbp_m  ·  beam_m  ·  depth_m  ·  max_draft_m  ·  summer_draft_m
Tonnage (vessels.js: dwt, gt, nt)
dwt_mt  ·  gt  ·  nt
Construction (vessels.js: yr, yard, hn, builtYard)
yr = year_built  ·  yard = shipyard  ·  hn = hull_number  ·  built_yard_cc = build_country_code
Machinery (vessels.js: eng, mcr, spd, fuel, prp)
eng = main_engine  ·  mcr_kw  ·  spd_kn = service_speed  ·  fuel = fuel_type  ·  prp = propulsion_type
Classification (vessels.js: cls, clsNot, ice, dp)
cls = class_society  ·  cls_not = class_notation  ·  ice = ice_class  ·  dp = dp_class
Ownership (vessels.js: ow, bo, op, mg, pi)
ow = registered_owner  ·  bo = beneficial_owner  ·  op = commercial_operator  ·  mg = technical_manager  ·  pi = pi_club
Safety & Green Tech (vessels.js: scrubberFitted, igs, cow, bowDisch, sternDisch, heli, bwmp, ffCap)
scrubber_fitted  ·  igs  ·  cow  ·  bow_disch  ·  stern_disch  ·  heli  ·  bwmp  ·  ff_cap
Cargo (vessels.js: teu, teu_r, ceu, pax, holds, hatches, lanm)
teu  ·  teu_r = teu_reefer  ·  ceu = car_units  ·  pax = passengers  ·  holds  ·  hatches  ·  lanm = lane_metres
Current Position (from vessel.latest_position JOIN)
lat  ·  lon  ·  sog = speed_kn  ·  cog = course_deg  ·  nav_status  ·  destination  ·  eta  ·  last_position_ts
