Design Principles

  • Each core entity (vessel, port, company) owns its own schema with an identical structural template: entity → raw_ingest (bronze) → attr_value (silver) → master_value (gold) → v_current (materialized view)
  • Vendor data never auto-promotes — workflow.promotion_request is the explicit human gate between silver and gold layers; registry.source_attr_weight.auto_promote_to_master is the opt-in bypass for fully trusted sources
  • Bi-temporal model: valid_from/valid_to (real-world time) + sys_from/sys_to (system recording time) on every EAV row; backdating supported by setting valid_from to any past date
  • Bronze and silver layers are immutable — raw_ingest tables are append-only; PostgreSQL RULEs prevent UPDATE/DELETE on all attr_value tables
  • Attribute catalog lives in registry.attribute_def; JS layer reads it at build-time via attributeRegistry.js
  • Feed-to-master field mappings versioned in ingest.feed_field_map with full history (valid_from / valid_to)
  • Materialized views (v_current, latest_position) read exclusively from the gold layer and refreshed CONCURRENTLY — zero downtime after each ingest run
  • Range partitioning on all high-volume tables: attr_value and master_value by year, position/raw_ingest by quarter

Schema → JSON → JS Layer Alignment

  • registry.attribute_def ← attribute_definitions.json — all filter_groups, column_groups, attr metadata
  • vessel.v_current columns ← vessels.js VESSELS object property names (nm, imo, dwt, ow…)
  • port.v_current columns ← ports_detail.json field names flattened (ch_max_draft, berth_count…)
  • company.v_current columns ← companies_detail.json field names flattened (fleet.owned → vessels_owned)
  • ingest.feed_config rows ← etl_feeds.json source definitions (seed data)
  • ui.persona rows ← personas.json (persona_key = JSON id, attr_sections, vessel_columns, dashboard_cards)
  • compliance.psc_inspection ← psc_inspections.json (external_id = psc_inspections.json "id")
  • market.fixture ← fixtures.json; market.tc_contract ← tc_contracts.json; market.route_benchmark ← freight_routes.json
