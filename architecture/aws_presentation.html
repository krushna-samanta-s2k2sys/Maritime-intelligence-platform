  • SHA-256 dedup · schema validation · SQS DLQ retry
  • S3 Bronze → Silver → Gold Medallion lake

  • Source hierarchy resolution (50+ source weights)
  • Conflict detection across concurrent feeds

  • SageMaker Pipelines for MLOps / model retraining
  • Model Registry — versioned model artefacts on S3
  • DuckDB for fast in-process feature engineering

  • Amazon OpenSearch Service — sub-100ms vessel search
  • Maritime synonym analyzers (IMO, MMSI, name)
  • Faceted filters: type, flag, class, route, status
  • Geo-point queries — port radius, voyage track
  • CDC-fed from S3 Gold via Airflow DAG near-real-time
  • Auto-complete · fuzzy match · saved searches
  • Multi-AZ OpenSearch domain with dedicated master
Vessel & Fleet Management EKS · Aurora · S3
  • 650+ vessel attributes across 13 attribute groups
  • Live AIS tracking · voyage history on Aurora PostGIS
  • DRAFT → IN_REVIEW → APPROVED edit workflow
  • Recursive AttrTreeSidebar + AttrContentPanel UX
  • Aurora PostgreSQL Serverless v2 for geo queries
  • Vessel images and docs via S3 + CloudFront CDN
  • Signed S3 URLs for per-document access control
Analytics & Reporting Athena · Redshift · QuickSight
  • Amazon QuickSight dashboards — fleet, route, port

  • Redshift Serverless for heavy analytics queries

  • Snowflake data share for financial analytics teams
  • Export: CSV, Excel, PDF, API feed, S3 direct
Observability & SRE Grafana · CloudWatch · X-Ray
  • Grafana Cloud dashboards pulling CloudWatch metrics
  • CloudWatch Logs + Metrics + Alarms (30-day retention)
  • AWS X-Ray distributed tracing (OpenTelemetry)

Security & Compliance KMS · GuardDuty · Macie
